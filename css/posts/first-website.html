Where I am Now

I don't know if I've already been to my rock bottom. But what I know is that I've already been to different bottoms of my life.

I have always been curious about how websites work. We visit them every day, but most of the time we don't think about what happens behind the screen.

Today, I finally decided to learn.

I'm starting with HTML and CSS. At first, the code looks confusing, but slowly I'm beginning to understand how everything fits together.

This website is going to be my little experiment. I'll use it to document things I learn, experiences I have, and thoughts I want to share.

I don't know exactly what this blog will become yet. And that's okay.

For now, I'm just excited to start.
